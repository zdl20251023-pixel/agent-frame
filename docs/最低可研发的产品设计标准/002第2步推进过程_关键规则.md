## 4. 关键规则

请按“业务范围 → 功能模块 → 具体对象 → 主规则 → 子规则 → 特殊情况 → 处理结果”的顺序说明，避免规则散着写。

### 规则 1：优惠券领取规则

* 规则对象：

  * 业务范围：优惠券活动流程
  * 功能模块：用户领取优惠券
  * 具体对象：用户、优惠券、优惠券活动

* 主规则：
  用户只能在活动有效期内领取符合条件的优惠券。

* 子规则：

  * 领取时间：当前时间必须在优惠券活动有效期内；
  * 领取次数：同一用户同一活动下只能领取一次。

* 特殊情况：
  如果优惠券已发放完，用户不能继续领取。

* 处理结果：
  满足领取条件时，优惠券进入用户账户；不满足条件时，领取失败，并提示失败原因。

---

### 规则 2：优惠券使用规则

* 规则对象：

  * 业务范围：下单支付流程
  * 功能模块：优惠券使用
  * 具体对象：用户、优惠券、订单

* 主规则：
  用户下单时，只能使用满足条件的优惠券抵扣订单金额。

* 子规则：

  * 有效期：优惠券必须在有效期内；
  * 使用门槛：订单金额必须达到优惠券使用门槛。

* 特殊情况：
  如果订单取消或退款，需要确认优惠券是否退回。

* 处理结果：
  满足使用条件时，优惠券可用于抵扣订单金额；不满足条件时，优惠券不可用，并提示不可用原因。
