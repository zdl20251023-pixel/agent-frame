# PRD 宣讲前 Checklist

| 检查项       | 宣讲前确认问题                                                   | 判断                      | 需要补充的问题 |
| ------------ | ---------------------------------------------------------------- | ------------------------- | -------------- |
| 需求目标     | 是否能让研发理解为什么做、解决谁的问题、本期不做什么？           | 是 / 否 / 待确认          |                |
| 本期范围边界 | 是否明确本期做什么、不做什么、主要影响范围？                     | 是 / 否 / 待确认          |                |
| 主流程       | 是否能让研发看懂整体流程、模块流程和关键节点？                   | 是 / 否 / 待确认          |                |
| 涉及范围     | 是否能让研发判断会改哪些端、后台、配置、服务端、系统或已有数据？ | 是 / 否 / 不涉及 / 待确认 |                |
| 关键规则     | 是否能让研发理解核心规则、细分判断、特殊情况和处理结果？         | 是 / 否 / 待确认          |                |
| 验收标准     | 是否能让研发知道验哪些范围、哪些场景算通过、哪些情况不通过？     | 是 / 否 / 待确认          |                |
| 待确认点     | 不明确的问题是否写清影响范围、默认处理、负责人和确认节点？       | 是 / 否 / 不涉及          |                |
| 异常处理     | 已知主要异常是否写清发生位置、处理方式和用户 / 系统表现？        | 是 / 否 / 不涉及 / 待确认 |                |
| AI 检查      | 是否已通过工具按以上检查项完成自动检查，并确认无明显缺口？       | 通过 / 未检查 / 需补充    |                |
