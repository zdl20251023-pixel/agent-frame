# 复盘结果反哺 Checklist 更新流程

仅在 PRD 被打回、评审中发现关键问题、影响研发评估 / 开工 / 验收，或同类问题反复出现时使用；评审正常通过时不强制填写。

优先调整已有检查项，不轻易新增检查项；只有高频且影响研发评估、开工或验收的问题，才新增检查项。

## 1. 更新判断

仅当评审问题属于高频问题、关键问题，或影响研发评估、开工、验收时，才反哺 Checklist；一次性细节问题先观察，不直接加入。

| 情况 | 是否建议反哺 |
|---|---|
| 同类问题反复出现 | 是 |
| 问题影响研发评估 | 是 |
| 问题影响研发开工 | 是 |
| 问题影响验收判断 | 是 |
| 问题导致 PRD 被打回 | 是 |
| 一次性细节问题 | 否，先观察 |
| 只影响局部文案或展示 | 否，先观察 |
