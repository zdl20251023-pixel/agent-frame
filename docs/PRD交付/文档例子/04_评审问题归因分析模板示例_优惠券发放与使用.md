# 评审问题归因分析模板（轻量版）示例：优惠券发放与使用

| 问题 | 对应 PRD 章节 | 问题类型 | 影响 | 是否反哺 Checklist | 说明 |
|---|---|---|---|---|---|
| 订单取消后优惠券是否退回未明确 | 待确认点 / 关键规则 | 待确认点缺失 / 规则不清 | 开工 | 是 | 该问题会影响优惠券状态、订单取消流程和用户可用券列表，属于开发前必须明确的问题，建议后续 Checklist 中加强“待确认点是否写清影响范围和确认节点”的检查。 |
| 后台修改优惠券活动配置后，是否影响已领取优惠券未明确 | 涉及范围 / 待确认点 | 范围遗漏 / 待确认点缺失 | 联调 | 观察 | 该问题影响管理后台配置和用户端展示，但不一定每类需求都会出现，先记录观察；如果后续配置类需求反复出现类似问题，再反哺 Checklist。 |
| 支付成功后优惠券状态更新失败的补偿处理未说明 | 异常处理 / 关键规则 | 异常处理缺失 / 规则不清 | 开工 | 是 | 该问题会影响优惠券状态一致性和重复使用风险，属于关键异常处理缺口，建议后续 Checklist 中关注“关键状态异常是否有处理方式”。 |
| 用户领取失败时需要展示哪些失败原因未明确 | 异常处理 / 验收标准 | 异常处理缺失 / 验收不清 | 验收 | 否 | 该问题主要影响用户提示和验收口径，属于一次性细节补充；当前不建议直接加入 Checklist。 |
