# 产品评审后复盘模板（极简版）示例：优惠券发放与使用

## 评审结论

| 需求名称 | 评审结论 | 是否可进入研发评估 | 是否可进入开发 | 进入下一步前必须补齐的问题 |
|---|---|---|---|---|
| 优惠券发放与使用 | 有条件通过 | 是 | 有条件 | 开发前必须补齐订单取消 / 退款后的优惠券退回规则；联调前确认后台配置变更是否影响已领取优惠券。 |

## 问题记录

| 主要问题 | 影响范围 | 修改动作 | 负责人 | 完成节点 | 是否需要二次确认 |
|---|---|---|---|---|---|
| 订单取消后优惠券是否退回未明确 | 影响优惠券状态、订单取消流程、用户可用券列表 | 产品补充订单取消后的优惠券退回规则，明确未过期、已过期两种情况的处理方式 | 产品负责人 | 开发前 | 是 |
| 订单退款后优惠券是否退回未明确 | 影响退款流程、优惠券状态、用户可用券列表 | 产品补充全额退款、部分退款下的优惠券处理规则 | 产品负责人 / 财务确认人 | 开发前 | 是 |
| 后台修改优惠券活动配置后，是否影响已领取优惠券未明确 | 影响管理后台配置、已领取优惠券、用户端展示 | 产品补充配置变更后的影响范围，明确只影响后续领取还是同时影响已领取优惠券 | 产品负责人 | 联调前 | 是 |
| 支付成功后优惠券状态更新失败的补偿处理未说明 | 影响支付流程、优惠券状态、重复使用风险 | 研发补充异常补偿方案，产品确认用户侧展示和最终状态口径 | 研发负责人 / 产品负责人 | 开发中 | 是 |
