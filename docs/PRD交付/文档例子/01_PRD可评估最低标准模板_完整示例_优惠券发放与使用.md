# PRD 示例：优惠券发放与使用【轻量优化版】

## 1. 需求目标

请用简短说明讲清楚：这个需求为谁解决什么问题，完成后希望达到什么结果。

* 目标用户 / 使用对象：

运营人员、下单用户。

* 当前问题：

目前运营无法灵活创建优惠券活动，用户下单时也没有统一的优惠券领取和抵扣能力。

* 目标结果：

运营可以在管理后台创建优惠券活动；用户可以在活动页领取优惠券，并在下单时使用优惠券完成订单金额抵扣。

* 本期做什么：

本期支持运营在管理后台创建优惠券活动，用户在活动页领取优惠券，并在下单页选择可用优惠券完成抵扣。

* 本期不做什么：

不包含复杂人群定向发券、不包含多平台联合优惠、不包含优惠券叠加使用、不包含复杂营销活动组合。

* 主要影响范围：

管理后台、用户端活动页、用户端下单页、优惠券服务端逻辑、订单金额计算、优惠券状态流转。

> 说明：
> 本期重点是打通优惠券从创建、领取、使用到状态更新的主流程，不追求覆盖所有复杂营销玩法。

---

## 2. 主流程

按照范围从大到小说明流程：先写整体流程，再写各功能模块流程，最后标出会影响研发实现的关键节点。

* 整体流程：

运营在管理后台创建优惠券活动 → 配置优惠券基础规则 → 用户进入活动页领取优惠券 → 优惠券进入用户账户 → 用户进入下单页 → 系统展示可用优惠券 → 用户选择优惠券 → 系统校验优惠券是否可用 → 订单金额完成抵扣 → 用户支付成功 → 优惠券状态更新为已使用。

* 模块流程：

  * 模块 1：优惠券配置

    运营进入管理后台 → 新建优惠券活动 → 填写优惠券名称、面额、有效期、发放数量、适用商品、使用门槛 → 保存配置 → 活动生效。

  * 模块 2：优惠券领取

    用户进入活动页 → 查看可领取优惠券 → 点击领取 → 系统判断活动是否有效、用户是否已领取、库存是否充足 → 领取成功后，优惠券进入用户账户。

  * 模块 3：优惠券下单使用

    用户进入下单页 → 系统查询用户可用优惠券 → 用户选择优惠券 → 系统校验有效期、使用门槛、适用商品 → 订单金额抵扣 → 用户提交订单并支付。

  * 模块 4：优惠券状态更新

    优惠券创建后为可领取 → 用户领取后为未使用 → 用户支付成功后为已使用 → 超过有效期后为已过期。

* 关键节点：

  * 运营保存优惠券配置后，用户端需要按配置展示可领取优惠券；
  * 用户领取时，需要判断活动是否有效、用户是否已领取、库存是否充足；
  * 用户下单时，需要判断优惠券是否在有效期内、订单金额是否满足门槛、商品是否适用；
  * 用户选择优惠券后，订单金额需要正确抵扣；
  * 支付成功后，需要更新优惠券状态，避免重复使用。

> 说明：
> 即使暂时没有界面效果图 / 原型图，研发、前端、测试也应能通过以上主流程理解：运营在哪里配置、用户在哪里领取、下单时怎么使用、系统如何校验、支付成功后状态如何变化。
> 本示例不要求补全所有页面状态、异常边界和按钮细节，只保证功能主路径可理解、可评估、可开发、可验收。

## 4. 关键规则

请按“业务范围 → 功能模块 → 具体对象 → 主规则 → 子规则 → 特殊情况 → 处理结果”的顺序说明，避免规则散着写。

### 规则：优惠券领取规则

* 规则对象：

  * 业务范围：优惠券活动流程
  * 功能模块：用户领取优惠券
  * 具体对象：用户、优惠券、优惠券活动

* 主规则：

用户只能在活动有效期内领取符合条件的优惠券。

* 子规则：

  * 活动有效时，用户可以领取优惠券；
  * 同一用户同一优惠券活动下只能领取一次；
  * 优惠券库存不足时，不能继续领取。

* 特殊情况：

如果用户已经领取过，或者优惠券已经发完，系统不允许再次领取。

* 处理结果：

满足领取条件时，领取成功，优惠券进入用户账户；不满足条件时，领取失败，并提示原因。

---

### 规则：优惠券使用规则

* 规则对象：

  * 业务范围：下单支付流程
  * 功能模块：优惠券使用
  * 具体对象：用户、优惠券、订单

* 主规则：

用户下单时，只能使用满足条件的优惠券抵扣订单金额。

* 子规则：

  * 优惠券必须在有效期内；
  * 订单金额必须达到优惠券使用门槛；
  * 订单商品必须在优惠券适用范围内；
  * 优惠券支付成功后变为已使用，不能再次使用。

* 特殊情况：

如果订单金额不满足门槛、商品不适用或优惠券已过期，则该优惠券不可用于抵扣。

* 处理结果：

满足使用条件时，优惠券可用于抵扣订单金额；不满足条件时，优惠券不可用，并提示不可用原因。

说明主流程中哪些情况出现时，不能算验收通过。

* 运营保存优惠券活动后，用户端无法按配置展示或领取；
* 用户符合领取条件，但无法领取优惠券；
* 用户已经领取优惠券，但下单页无法展示可用优惠券；
* 用户选择优惠券后，订单金额没有正确抵扣；
* 支付成功后，优惠券状态没有更新为已使用；
* 已使用优惠券仍然可以再次抵扣订单金额。
