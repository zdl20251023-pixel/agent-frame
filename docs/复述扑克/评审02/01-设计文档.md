# 一、背景介绍

## 1.1 需求介绍

本文档用于说明 **复式扑克 PvE 排名赛 7.15** 的研发设计方案。

本需求基于已有 AI 练习场 / drill PvE 能力，新增一个后台可配置的 PvE 排名赛活动。核心闭环如下：

```text
后台配置活动
-> 用户参加活动
-> 系统分配 N 手牌
-> 用户逐手完成 PvE 对局
-> 每手完成后计分
-> 完成 N 手后进入当前榜
-> 活动截止后结算最终榜
```

## 1.1.1 需求点整理

7.15 本期聚焦 6 个核心模块。

| 模块        | 说明                      |
| --------- | ----------------------- |
| 活动配置      | 后台配置活动、牌局包、挑战手数、活动时间    |
| 用户参赛与手牌分配 | 用户参加活动后生成参赛记录和固定 N 手牌   |
| PvE 对局与恢复 | 用户按顺序完成 PvE 对局，支持活动进度恢复 |
| 每手计分      | 每手完成后生成计分结果             |
| 当前榜 / 最终榜 | 完成 N 手进入当前榜，活动截止后生成最终榜  |
| 截止结算      | Worker 扫描到期活动并冻结最终排名    |

## 1.1.2 需求点细节

| 角色 / 模块 | 影响范围                                      |
| ------- | ----------------------------------------- |
| 用户端     | 活动入口、活动详情、开始挑战、继续挑战、进度展示、榜单展示             |
| 管理后台    | 手牌配置、牌局包配置、活动配置、活动发布                      |
| 服务端     | 用户参赛、手牌分配、PvE 接入、计分、进度推进、入榜、结算、恢复         |
| 数据库     | 新增 duplicate_match 相关表，支撑活动、参赛、手牌、计分、榜单闭环 |
| Redis   | 只用于排行榜缓存和活动结算锁，不作为事实源                     |

# 二、参考方案介绍

## 2.1 设计原则

| 原则           | 说明                                       |
| ------------ | ---------------------------------------- |
| MySQL 事实源    | 活动、参赛、手牌、计分、榜单、最终结算都以 MySQL 为准           |
| Redis 辅助     | Redis 只做排行榜分页缓存和活动结算锁                    |
| 完成 N 手才入榜    | 用户必须完成 `activity.play_hand_count` 才能进入榜单 |
| 当前榜 / 最终榜分离  | 当前榜动态查询，最终榜截止后冻结                         |
| 只恢复活动进度      | 不恢复单手中途牌局状态                              |
| 幂等兜底         | join、start hand、submit hand 需要支持重复请求     |
| 不影响普通 AI 练习场 | 排名赛复用 drill / PvE 能力，但数据闭环独立             |

## 2.2 数据结构

### 2.2.1 `duplicate_match_hand`：手牌基础表

用途：保存排名赛可引用的手牌，通过 `drill_id` 关联已有 drill 玩法。

| 字段           | 类型           | 说明               |
| ------------ | ------------ | ---------------- |
| `id`         | BIGINT       | 主键 ID            |
| `drill_id`   | BIGINT       | 关联已有 drill 玩法 ID |
| `title`      | VARCHAR(255) | 手牌名称             |
| `status`     | TINYINT      | 状态：启用 / 禁用       |
| `created_at` | DATETIME     | 创建时间             |
| `updated_at` | DATETIME     | 更新时间             |

关键索引：

| 索引             | 字段         | 说明            |
| -------------- | ---------- | ------------- |
| `idx_drill_id` | `drill_id` | 根据 drill 查询手牌 |
| `idx_status`   | `status`   | 后台筛选可用手牌      |

### 2.2.2 `duplicate_match_hand_pack`：牌局包表

用途：定义一组可用于活动分配的手牌集合。

| 字段           | 类型           | 说明         |
| ------------ | ------------ | ---------- |
| `id`         | BIGINT       | 主键 ID      |
| `name`       | VARCHAR(255) | 牌局包名称      |
| `status`     | TINYINT      | 状态：启用 / 禁用 |
| `created_at` | DATETIME     | 创建时间       |
| `updated_at` | DATETIME     | 更新时间       |

关键索引：

| 索引           | 字段       | 说明      |
| ------------ | -------- | ------- |
| `idx_status` | `status` | 查询可用牌局包 |

### 2.2.3 `duplicate_match_hand_pack_item`：牌局包手牌关联表

用途：维护牌局包和手牌的关联关系，支持必选手和随机候选手。

| 字段             | 类型          | 说明           |
| -------------- | ----------- | ------------ |
| `id`           | BIGINT      | 主键 ID        |
| `hand_pack_id` | BIGINT      | 牌局包 ID       |
| `hand_id`      | BIGINT      | 手牌 ID        |
| `item_type`    | VARCHAR(32) | 类型：必选 / 随机候选 |
| `sort_no`      | INT         | 排序值          |
| `created_at`   | DATETIME    | 创建时间         |
| `updated_at`   | DATETIME    | 更新时间         |

关键索引：

| 索引                 | 字段                      | 说明              |
| ------------------ | ----------------------- | --------------- |
| `idx_hand_pack_id` | `hand_pack_id`          | 查询牌局包下的手牌       |
| `uk_pack_hand`     | `hand_pack_id, hand_id` | 防止同一牌局包重复绑定同一手牌 |

### 2.2.4 `duplicate_match_activity`：活动配置表

用途：保存 PvE 排名赛活动配置。

| 字段                | 类型           | 说明                                   |
| ----------------- | ------------ | ------------------------------------ |
| `id`              | BIGINT       | 主键 ID                                |
| `title`           | VARCHAR(255) | 活动名称                                 |
| `hand_pack_id`    | BIGINT       | 绑定的牌局包 ID                            |
| `play_hand_count` | INT          | 用户需要完成的手数 N                          |
| `start_time`      | DATETIME     | 活动开始时间                               |
| `end_time`        | DATETIME     | 活动截止时间                               |
| `status`          | VARCHAR(32)  | 活动状态：draft / published / finalized 等 |
| `scoring_mode`    | VARCHAR(64)  | 计分模式                                 |
| `finalized_at`    | DATETIME     | 最终榜结算完成时间                            |
| `created_at`      | DATETIME     | 创建时间                                 |
| `updated_at`      | DATETIME     | 更新时间                                 |

关键索引：

| 索引                    | 字段                             | 说明            |
| --------------------- | ------------------------------ | ------------- |
| `idx_status_time`     | `status, start_time, end_time` | 活动列表和活动状态判断   |
| `idx_status_end_time` | `status, end_time`             | Worker 扫描到期活动 |

关键规则：

```text
play_hand_count 不能写死为 10。
完成判断、入榜判断、结算判断都必须基于 activity.play_hand_count。
```

### 2.2.5 `duplicate_match_user_entry`：用户参赛记录表

用途：记录用户在某个活动下的一次有效参赛记录。

| 字段                     | 类型            | 说明                                          |
| ---------------------- | ------------- | ------------------------------------------- |
| `id`                   | BIGINT        | 主键 ID                                       |
| `activity_id`          | BIGINT        | 活动 ID                                       |
| `user_id`              | BIGINT        | 用户 ID                                       |
| `status`               | VARCHAR(32)   | 参赛状态：joined / playing / completed / expired |
| `completed_hand_count` | INT           | 已完成手数                                       |
| `total_score`          | DECIMAL(10,2) | 当前总分                                        |
| `current_order_no`     | INT           | 当前进行到第几手                                    |
| `joined_at`            | DATETIME      | 参赛时间                                        |
| `complete_time`        | DATETIME      | 完成全部 N 手时间                                  |
| `expired_at`           | DATETIME      | 过期时间                                        |
| `created_at`           | DATETIME      | 创建时间                                        |
| `updated_at`           | DATETIME      | 更新时间                                        |

关键索引：

| 索引                    | 字段                     | 说明          |
| --------------------- | ---------------------- | ----------- |
| `uk_activity_user`    | `activity_id, user_id` | 防止同一用户重复参赛  |
| `idx_activity_status` | `activity_id, status`  | 查询活动下不同状态用户 |
| `idx_user_activity`   | `user_id, activity_id` | 用户恢复进度      |

### 2.2.6 `duplicate_match_user_hand`：用户手牌分配表

用途：记录用户参加活动后实际分配到的 N 手牌。

| 字段             | 类型          | 说明                               |
| -------------- | ----------- | -------------------------------- |
| `id`           | BIGINT      | 主键 ID                            |
| `entry_id`     | BIGINT      | 用户参赛记录 ID                        |
| `activity_id`  | BIGINT      | 活动 ID                            |
| `user_id`      | BIGINT      | 用户 ID                            |
| `hand_id`      | BIGINT      | 手牌 ID                            |
| `order_no`     | INT         | 用户本次挑战中的顺序                       |
| `source_type`  | VARCHAR(32) | 来源类型：必选 / 随机                     |
| `status`       | VARCHAR(32) | 状态：pending / playing / completed |
| `started_at`   | DATETIME    | 开始时间                             |
| `completed_at` | DATETIME    | 完成时间                             |
| `created_at`   | DATETIME    | 创建时间                             |
| `updated_at`   | DATETIME    | 更新时间                             |

关键索引：

| 索引                  | 字段                     | 说明               |
| ------------------- | ---------------------- | ---------------- |
| `uk_entry_order`    | `entry_id, order_no`   | 防止同一参赛记录下顺序重复    |
| `uk_entry_hand`     | `entry_id, hand_id`    | 防止同一参赛记录重复分配同一手牌 |
| `idx_entry_status`  | `entry_id, status`     | 查询当前进度           |
| `idx_activity_user` | `activity_id, user_id` | 用户恢复进度           |

### 2.2.7 `duplicate_match_hand_score`：每手计分结果表

用途：保存用户每一手 PvE 对局完成后的计分结果。

| 字段             | 类型            | 说明      |
| -------------- | ------------- | ------- |
| `id`           | BIGINT        | 主键 ID   |
| `activity_id`  | BIGINT        | 活动 ID   |
| `entry_id`     | BIGINT        | 参赛记录 ID |
| `user_hand_id` | BIGINT        | 用户手牌 ID |
| `hand_id`      | BIGINT        | 手牌 ID   |
| `user_id`      | BIGINT        | 用户 ID   |
| `raw_result`   | JSON          | 原始结果    |
| `win_loss_bb`  | DECIMAL(10,2) | BB 输赢结果 |
| `score`        | DECIMAL(10,2) | 0-100 分 |
| `score_status` | VARCHAR(32)   | 分数状态    |
| `scored_at`    | DATETIME      | 计分时间    |
| `created_at`   | DATETIME      | 创建时间    |
| `updated_at`   | DATETIME      | 更新时间    |

关键索引：

| 索引                  | 字段                     | 说明           |
| ------------------- | ---------------------- | ------------ |
| `uk_user_hand`      | `user_hand_id`         | 防止同一手牌重复计分   |
| `idx_entry`         | `entry_id`             | 查询用户本次活动所有计分 |
| `idx_activity_user` | `activity_id, user_id` | 查询用户活动计分     |

### 2.2.8 `duplicate_match_leaderboard_result`：榜单结果表

用途：保存完成 N 手用户的榜单结果，当前榜和最终榜共用该表。

| 字段              | 类型            | 说明      |
| --------------- | ------------- | ------- |
| `id`            | BIGINT        | 主键 ID   |
| `activity_id`   | BIGINT        | 活动 ID   |
| `entry_id`      | BIGINT        | 参赛记录 ID |
| `user_id`       | BIGINT        | 用户 ID   |
| `total_score`   | DECIMAL(10,2) | 总分      |
| `complete_time` | DATETIME      | 完成时间    |
| `rank_no`       | INT           | 最终排名    |
| `is_final`      | TINYINT       | 是否最终榜   |
| `finalized_at`  | DATETIME      | 最终榜冻结时间 |
| `created_at`    | DATETIME      | 创建时间    |
| `updated_at`    | DATETIME      | 更新时间    |

关键索引：

| 索引                   | 字段                                                  | 说明             |
| -------------------- | --------------------------------------------------- | -------------- |
| `uk_entry`           | `entry_id`                                          | 防止同一参赛记录重复入榜   |
| `uk_activity_user`   | `activity_id, user_id`                              | 防止同一用户同一活动重复入榜 |
| `idx_activity_score` | `activity_id, is_final, total_score, complete_time` | 支持榜单排序查询       |
| `idx_activity_rank`  | `activity_id, is_final, rank_no`                    | 支持最终榜分页查询      |

排序规则：

```text
total_score DESC
complete_time ASC
```

当前榜：

```text
动态查询，不强制写入 rank_no。
```

最终榜：

```text
Worker 结算后写入 rank_no、is_final、finalized_at。
```
